Статусы: ⬜ не начата · ◐ в работе · ✅ завершена (+дата). Статус обновляется в этой таблице и в шапке файла сессии.
Колонка «Фичи» — фичи из `feature_list.json`, с которыми работает сессия; в ячейке — роль сессии по фиче: **«закрывает»** (финальная сессия фичи, доводит до `passing` через `make verify-feature`) или **«продолжает»** (промежуточная; фича остаётся `active`). Одна фича может занимать несколько сессий — закрывает ровно одна; зависимости фич согласованы с графом зависимостей сессий.

## Правила параллельной работы

1. Не трогать файлы чужого трека (карта владения выше); общие файлы — только дословно из S00 или по согласованию.
2. Стыки треков — только через контракты S00 («Контракты стыка»); изменение контракта = правка S00 + согласование в том же PR.
3. Обнаруженное вне скоупа сессии — в `solution/backlog.md`, не в чат и не в чужую сессию.
4. Статусы сессий обновляются в таблице выше по факту закрытия; «Текущее состояние» — при clock-out.
