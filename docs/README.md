# Documentation Map — карта документации

Папка `docs/` — архитектурная документация проекта. Агент читает нужный раздел на старте сессии (Startup Workflow в `AGENTS.md`); изменения — в том же коммите, что и код (правило «no stale docs»).

| Раздел | Что здесь | Когда читать/писать |
|---|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | Сводка архитектуры: компоненты, границы, инварианты | Обзор системы; перед архитектурными решениями |
| [adr/](adr/README.md) | **Architecture Decision Records** — реестр ключевых решений с альтернативами, последствиями и revisit-триггерами + [шаблон](adr/ADR-TEMPLATE.md) | Перед значимым решением; после — новый ADR в реестр |
| [api/](api/README.md) | **Контракт API** — OpenAPI 3.1 (`openapi.yaml`), правила версионирования | Spec-first: правка контракта до реализации |
| [diagrams/](diagrams/README.md) | **Диаграммы**: [модель данных ER](diagrams/er-data-model.md) (каноническая), [C4 контекст/контейнеры](diagrams/c4-context.md), sequence-сценарии | Изменение схемы/топологии — в том же PR |
| [PRODUCT.md](PRODUCT.md) | Продукт: что, зачем, для кого, non-goals | При неясных требованиях |
| [quality-document.md](quality-document.md) | Оценка модулей A/B/C/D по 4 измерениям | В конце сессии (End of Session, шаг 5) |

## Приоритет источников при конфликте

1. **Канон S00** (`solution/sessions/S00_session.md`) — стек, порты, контракты стыков и запреты проекта;
2. **ADR** (`docs/adr/`) — зафиксированные решения с обоснованием;
3. **ER-модель** (`docs/diagrams/er-data-model.md`) и **OpenAPI** (`docs/api/openapi.yaml`) — канонические схемы данных и API;
4. **ARCHITECTURE.md** — сводка, синхронизируемая с ADR;
5. Рабочие сессии (`solution/sessions/`) — история исполнения; задним числом не редактируются;
6. `DECISIONS.md` (корень) — оперативные решения сессий; если решение архитектурно значимое, оно переносится в ADR.

Расхождение между источниками (или между документом и кодом) — не тихая правка: запись в `solution/FIXES.md`, решение владельца, синхронная правка всех затронутых мест в том же PR.
